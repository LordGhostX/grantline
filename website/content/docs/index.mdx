Grantline is the financial authority layer between an AI agent's intent and execution.

The agent proposes an action. Grantline checks the active authority and returns `ALLOW`, `ESCALATE`, or `DENY` before the Vault moves capital.

## Current implementation

The current contracts MVP runs on X Layer testnet. It includes:

- Vault custody and onchain execution events
- typed `TRANSFER` Action Plans and EIP-712 signatures
- inherited Mandate rules and native-balance Preflight
- owner-approved escalation and revocation
- delegation to sub-agents with bounded authority

The docs describe this implementation first. Guardians, sponsored submission, event indexing, SDK and API surfaces, production valuation, and assembled Decision Receipts are planned work, not current features.
